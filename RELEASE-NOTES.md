# MoleDPI v1.0.0 — Experimental Community Release
**Experimental software. Bugs, disconnections and network interruptions may occur. This version number does not certify compatibility or security.**

## Install
Download MoleDPI.dmg, open it, drag MoleDPI onto Applications and launch it from Applications. Click the menu-bar helmet and Connect. Approve the local helper when macOS asks.

Apple Silicon only. macOS 13+ deployment target, tested on macOS 27. This build is hardened and ad-hoc signed, **not Apple-notarized**. Gatekeeper may block it. Do not disable system security. See README for current installation limitations.

## Included
Source-built zapret tpws, verified TCP/PF sessions, automatic recovery with manual Disconnect priority, encrypted DNS recovery, reviewed diagnostics, last verified strategy preference, wake/path checks and optional GitHub update checking. No subscription, paid API or developer-operated relay.

## Remaining limits
Clean-Mac acceptance, full graphical uninstall, real sleep/wake and Wi-Fi transition coverage, older macOS versions and independent root-helper security review remain pending. No UDP voice/game bypass is claimed. IP addresses are not hidden. Ordinary DNS outside the recovery path follows system configuration.

Short automated tests and local live checks are described in RELEASE-TESTS.md. Source and all bundled notices are provided with this experimental release.
